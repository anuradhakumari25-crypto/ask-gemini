# Ask Gemini – AI Q&A Web Application

## About the Project
Ask Gemini is a web application that allows users to ask questions and receive AI-generated answers using the Google Gemini API.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Google Gemini API
- HTML and CSS

## Features
- Ask questions and receive AI-generated responses.
- Communicate with the Gemini API through a backend.
- Handle API requests and responses.

## Installation and Setup
1. Clone this repository.
2. Install dependencies using `npm install`.
3. Create a `.env` file and add your Gemini API key.
4. Start the server using the command specified in `package.json`.

## Security
Never share your API key publicly. Keep it in your environment variables.
